Authorize access to your encrypted data using a signed permit. To open it, select **New** in the Generated permits section.


## Screen components

1. **Permit explanation.** Describes the signature that proves control of the connected wallet.
2. **Permit Name.** Add an optional name so you can recognize this permit later.
3. **Set Expiration.** Choose a preset or enter a custom duration.
4. **Generate New.** Open the permit-signing request in your connected wallet.

## Steps

<Steps>
  <Step title="Check the wallet">
    Confirm that the correct wallet is connected.
  </Step>
  <Step title="Set a name and expiration">
    Name the permit and choose how long it lasts.
  </Step>
  <Step title="Generate and review">
    Select **Generate New** and review the signature request.
  </Step>
  <Step title="Sign">
    Sign to create the permit, then return to your balances.
  </Step>
</Steps>

<Note>
Creating a viewing permit is a message-signing step, not a token transfer. Review the requested access and duration before you sign.
</Note>
