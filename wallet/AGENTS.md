# Wallet Module docs

Pages under `wallet/` document the Fhenix Wallet Module, served at `/wallet/...`. The root `AGENTS.md` and `STYLE.md` apply here too.

The guide has one page per screen, grouped as Get started, Use the wallet (Balances and tokens, Moving assets, Settings and permits management), and Help (Troubleshooting, FAQ). Screenshots live in `wallet/images/`.

Yonatan and Alex review wallet changes.

## Facts

- Never write a technical claim you have not verified against the current source of the relevant repo or the published packages. Docs drift is the failure mode this project exists to fix.
- Current behavior and future plans never mix. Label future work as such, on its own page.
- No internal names: hostnames, cloud project names, environment names, deployment bundle names, feature flags.
- Never link to a private repository; readers get a 404.
