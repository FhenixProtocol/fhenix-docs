---
title: "Gas per Operation"
description: "The expected gas of every FHE.sol operation"
---

Every value is measured on the deployed contracts and rounded to the nearest 100 gas.

<Note>
**The values are for the first FHE call in a transaction. Every later FHE call in the same transaction costs about 20,000 gas less.**
</Note>

`X` stands for the encrypted type: `asEuint32`, `asEbool`, `shareEuint64`, and so on. The seven encrypted types are `ebool`, `euint8` through `euint128`, and `eaddress`; "All" means all seven. The type barely changes the price, so each value is the highest across the supported types.

## Cast between encrypted types

| Operation | Gas | Types |
|---|---|---|
| Cast `asX(eY)`, target not `ebool` | 45,900 | Any to `euint8` to `euint128` |
| Cast to `ebool`, `asEbool(eY)` | 75,800 | Numeric types and `eaddress` to `ebool` |

A cast to `ebool` costs more because `FHE.sol` implements it as `ne(value, asX(0))`: two TaskManager tasks instead of one.

## Access control

All access-control operations support all seven types and cost the same for each. The two `is*` functions are `view`; they cost gas only when a contract calls them inside a transaction.
